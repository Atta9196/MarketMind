# MarketMinds Frontend

React + Vite single-page application for the MarketMinds platform.

For full setup instructions, API documentation, and project overview, see the [root README](../README.md).

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173 (requires the backend running on port 8000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Create production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run Oxlint |
